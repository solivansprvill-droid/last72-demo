# 方块末日：最后72小时（LAST 72 HOURS）

> 原创作品 · 体素风格 3D 生存游戏 · 中文 · 手机横屏触屏 + 电脑键鼠
> 在线试玩：https://solivansprvill-droid.github.io/last72-demo/ （一局约 30 分钟，自动存档）

## 游戏简介

新曙光市在三天前被一场未知疫情吞没，大半市民变成了感染者。军方宣布：**72 小时后**，最后一架直升机将在**北部撤离区**接应幸存者。

你在一间公寓里醒来。搜刮物资、建造防线、熬过三次尸潮、找回通讯设备修好电台、救下城里的幸存者——然后在倒计时结束前抵达撤离区。也许，你会选择留下。

## 玩法

- **搜刮**：砍树、拆家具、翻冰箱和物资箱，获得木材、石料、金属、布料、电子零件、燃油、食物和水。
- **建造**：在基地放置工事，抵御夜间尸潮；损坏的工事可修理。
- **尸潮**：第 1、2、3 夜各有一次尸潮（约第 18、42、66 小时），最终尸潮出现巨型感染者。
- **任务链**：醒来 → 找水和食物 → 收集木材 → 建立基地 → 抵御第一次尸潮 → 超市补给 → 警察局拿通讯设备 → 医院找医生/药品 → 修复电台联系军方 → 72h 前往北部撤离区。屏幕顶部箭头、橙色光柱和小地图橙点指向当前目标。
- **五个相连街区**：居民公寓（起点，可上 3 楼）→ 大型超市 → 警察局 → 中心医院（可上 3 楼）→ 北部撤离区。

## 系统说明

- **背包与合成**：背包 16 格，同类物品自动堆叠（材料 40 一组）；点选物品可使用、装备、丢弃。在工作台（公寓 1 楼自带，也可建造）合成：木棍、钢管、消防斧（武器有耐久），绷带、净水（脏水煮沸）、罐头。
- **工事（10 种）**：木墙、路障、尖刺陷阱、门（可开关）、窗、储物箱（24 格）、工作台、瞭望塔（登高远望，感染者难以触及）、发电机、照明灯。
- **发电机与照明灯**：给发电机加燃油（1 份 = 6 小时），夜间为 14 格内的照明灯供电；灯光范围内感染者减速，游荡的感染者会避开光源。发电机运转有噪音。
- **感染者（5 种）**：游荡者、奔跑者、攀爬者（能翻越 2 格高的墙和车）、爆裂者（接触后爆炸，损毁工事）、巨型感染者（最终尸潮 Boss，范围砸毁路障）。被击倒后碎成方块，无血腥内容。
- **声音吸引**：战斗、拆车、爆炸、发电机、猎人的弩都会把附近感染者引来调查。雨声和浓雾会降低感染者的察觉范围。
- **幸存者（3 名）**：超市仓库的工程师老周（要 罐头×1）、警察局的猎人阿青（要 净水×2）、医院 3 楼的林医生（要 2 楼的急救药品箱）。可下令 跟随 / 守卫 / 工作，给他们食物。他们会饿、有士气：医生回血并可请求治疗；工程师让附近建造与修理更省材料、工作时自动修墙；猎人远程射击感染者、工作时可带回猎物。
- **疲劳与感染**：疲劳随时间、奔跑、战斗上升，过高会减慢体力恢复和移动；在公寓 1 楼你的床上睡觉可加速时间并恢复。被咬会提高感染值，超过 50 会自行恶化，达到 100 即“感染”结局；药品、医生可以降低。
- **天气**：第 1 天下午、第 2 天夜里、第 3 天下午有雨；第 2、3 夜有浓雾。
- **结局（5 种）**：全员撤离（带三名同伴登机）、独自撤离、留守（直升机到达后选择留守，或错过直升机）、感染、阵亡。修好电台后直升机停留到第 78 小时，否则只到第 75 小时。
- **存档**：每 2 个游戏小时与暂停时自动存档到浏览器本地；标题界面“继续游戏”。设置可调画质（低/中/高）、音量、视角灵敏度、屏幕震动。

## 技术与测试

- 引擎：Babylon.js（Apache-2.0，优先官方 CDN，`vendor/` 为备用副本）。所有模型为代码拼搭的体素方块；所有音效为 WebAudio 实时合成，无任何音频/贴图文件。
- 代码结构：`js/game/`（纯逻辑，无渲染依赖：世界生成、物理、导航、感染者、NPC、建造、物品、存档）、`js/render/`（Babylon 渲染、粒子、天气）、`js/ui/`（HUD、输入、小地图）、`js/audio/`（合成音效）。
- 性能：同时活跃感染者上限 35；感染者/碎块/粒子使用 thin instance；感染者 AI 分帧决策，远处游荡者降频更新并回收；区块按视距显示；流场寻路只计算玩家附近。
- 测试：`node tests/logic.mjs`（攀爬/爆裂/Boss/爆炸/楼梯/性能）、`node tests/sim.mjs`（逻辑模拟跑完 72h，五种结局路径）、`node tests/e2e.cjs [m]`（Headless Chromium，1280×720 与 844×390 触屏，按 `tests/cases.json` 逐项检查）。截图在 `shots/`。

## 已知问题

- 尚未在真机上测试本版本（P0 已在 Redmi K60 上可玩）；低端机建议在设置里选“低”画质。
- 感染者在建筑内的寻路较简单，偶尔会在门洞或家具旁短暂卡住（会自动侧移或拆工事）。
- 第三人称相机在室内狭窄处可能贴近墙体。
- 楼梯井在上层楼板有开口，可能失足掉回楼下（无摔落伤害）。
- 存档不保存感染者位置，读档后重新刷出；尸潮进行中读档会按剩余数量继续。
- 汽车前后部分只有 1 格高，普通感染者也可能踩上车顶（攀爬者额外能翻 2 格墙）。

## 移植到 造化（Babylon 模板）

1. 用 造化 插件创建 `basic-builder-cli/babylon` 模板工程（需要先登录 造化）。
2. 把 `js/game/`、`js/audio/`、`js/ui/`、`js/render/`、`style.css` 复制进工程源码目录；`index.html` 中的 HUD/菜单 DOM 片段合并到模板页面。
3. 模板已自带 Babylon.js 时，删除 `index.html` 里的 CDN/备用加载脚本，改为直接 `import('./js/main.js')`；`renderer.js` 通过 `window.BABYLON` 取引擎对象，如模板使用 ES 模块版 `@babylonjs/core`，在入口处 `window.BABYLON = BABYLON` 即可。
4. 纯逻辑层 `js/game/` 不依赖任何引擎，可原样复用；如需换成 天工引擎，只需重写 `js/render/`。
5. 发布前在模板中保留标题界面的“原创作品”标签与 `CREDITS_AI.md`。
