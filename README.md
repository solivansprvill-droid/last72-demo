# 方块末日：最后72小时 · LAST 72 HOURS（P0 试玩原型）

原创作品 · 试玩版。第三人称 3D 体素丧尸生存游戏，浏览器即玩（手机 Chrome 触屏 / 电脑键鼠）。

- 一局 72 游戏小时 ≈ 15.6 分钟（1 小时 = 13 秒）
- 任务：醒来 → 找水和食物 → 收集木材 → 建立基地 → 抵御第一次尸潮 → 坚守 → 撤离
- 尸潮：第 18h、42h、68h（夜间，规模递增）；空投：30h、54h；第 72h 直升机抵达北部撤离点，停留 5 小时

## 操作
- 手机：左下拖动移动（推到底奔跑），右侧拖动转视角，点按物体采集/攻击；按钮 攻击/跳跃/交互/建造/背包；建造模式点地面选位置后按“放置”
- 电脑：WASD 移动，Shift 奔跑，空格 跳，左键 攻击/采集（首次点击锁定鼠标），右键拖动转视角，E 交互/修理，B 建造，1/2/3 选择工事，F 吃，G 喝，Tab 背包，Esc 暂停

## 结构
- `js/game/` 纯逻辑（世界、物理、寻路、感染者、时钟/尸潮、建造）——不依赖渲染
- `js/render/renderer.js` Babylon.js 渲染（全部为体素立方体）
- `js/ui/` 输入与 HUD
- `vendor/babylon.js` Babylon.js 备用副本（Apache-2.0），默认优先加载官方 CDN

测试快进：`index.html?t=17` 从第 17 小时开始。
